# AGENTS.md

## Project Snapshot

YAH (Yet Another Harness) is a Discord-first computer-use agent that wraps [pi-sdk](https://github.com/earendil-works/pi). The current direction is a Category -> Channel -> Thread context tree with dashboard-managed configuration and memory.

## Code Priorities

1. Keep changes minimal.
2. Favor the context and memory plans in `PLAN-FOR-FUTURE.md` and `PLAN-FOR-MEMORY.md`.
3. Do not reintroduce self-improvement flows, repo-editing skills, or chat providers that do not support category/channel/thread-style context.
